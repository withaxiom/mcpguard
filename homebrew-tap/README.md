# withaxiom/homebrew-tap

Homebrew formulae for AXIOM tools.

## Install MCPGuard

```bash
brew tap withaxiom/tap
brew install mcpguard
```

## Note

This tap is auto-updated by GoReleaser on each release.
The formula in this directory is a template — the actual tap lives at
[github.com/withaxiom/homebrew-tap](https://github.com/withaxiom/homebrew-tap).
